## 정한 것과 아직 정하지 않은 것

- 정함: 08시 배치는 발송 작업(`PENDING`)만 만들고 끝난다. 각 서버의 DB 워커가 DB 폴링으로 빈 칸 수만큼 선점(`PROCESSING`, `claim_token`, `lease_until`)해서 보내고, 토큰이 맞을 때만 결과를 저장한다. 점유가 끝난 작업은 다른 워커가 회수한다.
- 정함: RabbitMQ·Outbox는 DB 워커의 한계를 측정한 뒤 다시 판단한다.
- 정함: 인앱 알림은 Redis Pub/Sub + SSE.
- 미정: 첫 발송과 재시도의 배분 비율, 폴링 간격.
- 미정: 컨슈머·워커를 어느 인프라에 둘지(클라우드 팀 결정).
