# 하지 말 것과 대신 할 것

다먹자 알림 작업(2026-10~11)에서 사용자가 싫어했던 것이다. 항목마다 대신 할 것을 함께 적는다.
같은 수정을 두 번 받으면 여기에 날짜와 함께 추가한다.

| 하지 말 것 | 대신 할 것 | 검사 |
|---|---|---|
| 글로 가득 찬 화면, 대시보드 같은 그래프 | 상자 몇 개와 움직이는 점, 상자 아래 숫자 하나 | 스크린샷 |
| 숫자만 올라가는 정적인 화면 (모든 종류에서 금지) | 점이 상자 사이를 움직이게 한다. ①②도 요청 점이 지나간다 | 스크린샷 |
| 끝에서 뚝 떨어지는 곡선 | 마지막 값을 유지한다. 막대가 더 나으면 막대를 쓴다 | 스크린샷 |
| 차이가 없는 상황을 그대로 둔 것 | 명세 단계에서 뺀다. 두 패널의 결과가 다른 상황만 남긴다 | 명세 확인 |
| 무엇을 뜻하는지 이름 없는 상자 | 상자마다 "무엇이 들어 있는지"를 이름으로 붙인다 | CONFIG `label` |
| 갑자기 생기는 점 | 처음부터 출발 상자에 두거나, 다른 점에서 갈라져 나오게 한다 | 스크린샷 |
| 겹치는 선 | `edges.pts`로 경로를 직접 잡는다 | check.js 선 겹침 |
| 기호로 된 작업명("#9") | "발송 작업 생성", "재시도 대기"처럼 한국어로 | 글 확인 |
| 대화체("~야")나 긴 용어 풀이 | 해요체, 풀이 줄 30자 안팎 | 글 확인 |
| 여러 번 나눠 고쳐 결과가 계속 바뀌는 것 | 받은 수정을 모아 한 번에 반영하고 검사를 다시 돌린다 | — |
| 노트북 비율이 깨진 세로로 긴 화면 | 16:10 안에 넣는다. 넘치면 배치를 바꾸고 미리보기로 확인받는다 | check.js 16:10 |
| 설명 영역 없이 그림만 있는 화면 | 모든 상황에 카드 두 개와 단계 ①②③ | check.js 단계 3개 |
| 선 있는 표, 원색으로 꽉 찬 머리띠, 회색 바탕의 설명 영역 | 연한 주황/파랑 카드, 작은 색 점과 색 글자 머리띠 | 뼈대에 들어 있음 |
| 단계 한 줄로만 줄어 용어 풀이와 "왜 다른지"가 빠진 설명 | 본문 + 풀이 두 줄. 풀이에 왜 다른지와 용어 뜻 | 글 확인 |
| 화면에 가정·조건을 적은 것 | README "시뮬레이션 가정"에 적는다. ③의 `예측 · 실측 전` 이름표만 예외 | 글 확인 |
